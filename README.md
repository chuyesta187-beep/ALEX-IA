# ALEX — Muy pronto

Proyecto inicial de la app ALEX (Expo / React Native).

## Incluye
- Pantalla negra con el logotipo morado.
- Texto MUY PRONTO.
- Cuenta regresiva al 4 de diciembre de 2026 a las 00:00 (hora de Colombia).
- Al llegar a cero, el contador permanece en 00:00:00 y MUY PRONTO sigue visible.

## Archivos
- `App.js`: pantalla y contador.
- `app.json`: nombre, icono y configuración de Android/iOS.
- `eas.json`: perfil APK de prueba y perfil de producción.
- `assets/`: iconos e imagen de presentación.

Este paquete es el código fuente; todavía no es un APK compilado.
